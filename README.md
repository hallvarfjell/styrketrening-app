
# Styrketreningsapp

Publiseres på GitHub Pages. Import/eksport via CSV; TCX‑eksport per dag.

## Kom i gang
1. Last opp hele mappen til GitHub.
2. Aktiver **Settings → Pages → Deploy from a branch → main → /**.
3. Åpne URLen som vises.

## Import
Gå til **Øktvelger** og dra inn `docs/sample_exercises.csv` og `docs/sample_workouts.csv`.

## Eksport
TCX eksport i Logg; bibliotek eksporteres som CSV i Øktvelger.
